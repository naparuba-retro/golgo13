# Crédits et mentions

- **Golgo 13** (jeux d'arcade) © Namco (aujourd'hui Bandai Namco) / Saito Production / Shogakukan. *Golgo 13* (manga) de Takao Saito.
  Aucune ROM, aucun code ni aucune image des jeux n'est distribué dans ce dépôt : tout ce qui en dérive (code recompilé, images traduites, polices cuites, images de cartes) est fabriqué sur la machine de l'utilisateur à partir de ses propres fichiers et ignoré par git.
- Les illustrations du README montrent quelques cases du manga *Golgo 13* à titre d'illustration ; elles restent la propriété de leurs ayants droit.
- **SDL3** (zlib license) — https://libsdl.org
- **minimp3** (CC0) — https://github.com/lieff/minimp3 (téléchargé par `tools/setup_deps.py`, non redistribué ici).
- **MAME** (https://www.mamedev.org) sert de référence pour comprendre le matériel (cartes System 12 / System 10, H8, GTE, SPU, C352, déchiffrement de la NAND). Certaines tables et certains algorithmes du port s'en inspirent ; MAME est distribué sous BSD-3-Clause (la plupart des fichiers) et GPL-2.0+ (certains) : à vérifier fichier par fichier avant toute réutilisation.
- Polices du menu : cuites localement à partir des polices installées sur la machine (Impact, Comic Sans sous Windows ; DejaVu sous Linux), non redistribuées.
